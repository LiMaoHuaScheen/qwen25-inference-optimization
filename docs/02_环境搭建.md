# 02 环境搭建

## 依赖安装

### 1. PyTorch（CUDA 12.8）

```
pip install torch torchvision --index-url https://download.pytorch.org/whl/cu128
```

中国大陆可使用阿里云镜像：

```
pip install torch torchvision --index-url https://mirrors.aliyun.com/pypi/simple/
```

### 2. Transformers + bitsandbytes

```
pip install transformers bitsandbytes accelerate --index-url https://mirrors.aliyun.com/pypi/simple/
```

- transformers >= 4.40（支持 BitsAndBytesConfig）
- bitsandbytes >= 0.43（NF4 + 双重量化）
- accelerate（device_map 自动分配）

### 3. 验证安装

```
python -c "import torch; print(torch.cuda.is_available())"
python -c "import bitsandbytes; print(bitsandbytes.__version__)"
```

## 模型下载

### 方式 1：HuggingFace CLI

```
huggingface-cli download Qwen/Qwen2.5-0.5B --local-dir hf_cache/Qwen2.5-0.5B
```

中国大陆使用镜像：

```
export HF_ENDPOINT=https://hf-mirror.com
huggingface-cli download Qwen/Qwen2.5-0.5B --local-dir hf_cache/Qwen2.5-0.5B
```

### 方式 2：Python 脚本

```
from huggingface_hub import snapshot_download
snapshot_download(repo_id="Qwen/Qwen2.5-0.5B", local_dir="hf_cache/Qwen2.5-0.5B")
```

## 常见问题

### bitsandbytes 导入失败

Windows 下可能需要安装 Visual C++ Build Tools：

```
pip install bitsandbytes --prefer-binary
```

### CUDA 版本不匹配

检查 PyTorch 与 CUDA 版本：

```
python -c "import torch; print(torch.version.cuda)"
nvidia-smi
```

确保 driver 版本 >= CUDA 版本。
