# 05 操作步骤（快速版）

## 1. 安装依赖

```
pip install -r requirements.txt
```

## 2. 下载模型

```
huggingface-cli download Qwen/Qwen2.5-0.5B --local-dir hf_cache/Qwen2.5-0.5B
```

## 3. 下载数据

```
python code/download_data.py
```

## 4. 运行基准测试

```
python code/bench_optimize.py
```

## 5. 生成图表

```
python code/plot_optimize.py
```

## 6. 查看结果

- 图表：`output_optimize/optimization_bar.png`
- 详细数据：`output_optimize/benchmark.json`
