# 03 操作步骤

## 1. 运行基准测试

```
python code/bench_optimize.py
```

参数说明：

| 参数 | 默认值 | 说明 |
|------|--------|------|
| --model | hf_cache/Qwen2.5-0.5B | 模型路径 |
| --data | datasets/alpaca_gpt4_data_zh.json | 数据集路径 |
| --output | output_optimize/ | 输出目录 |
| --n_eval | 100 | 评估样本数 |
| --n_gen | 8 | 生成样本数 |
| --max_new_tokens | 128 | 最大生成 token 数 |
| --max_len | 512 | 最大序列长度 |

脚本流程：

1. **加载 FP16 基线**：测量 PPL + 显存 + 解码速度
2. **加载 INT4 NF4**：测量 PPL + 显存 + 解码速度
3. **生成样本对比**：各方案生成 3 条样本保存到 benchmark.json

输出：

- `output_optimize/benchmark.json`：完整结果（含生成样本）
- 控制台打印各方案指标

## 2. 生成可视化图表

```
python code/plot_optimize.py
```

输出：`output_optimize/optimization_bar.png`（PPL / 显存 / 吞吐量三联柱状图）
